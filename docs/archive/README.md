# Roshan documentation archive

This directory preserves historical project records after the active documentation was consolidated on 2026-11-25. Files are archived, not deleted; original Git history remains available.

## Archive rules

- Historical records are evidence of what was known or done at their timestamp. They are not current status or release authorization.
- The former append-only master plan is preserved as `MASTER_PLAN_HISTORY.md` without content changes.
- The previous root README is preserved as `README_HISTORY_2026-11-25.md`.
- Early phase reports formerly at the repository root are preserved under `root-reports/`; root paths now contain compatibility pointers.
- The former execution ledger and 2026-10-18 deep research report are preserved here; their root docs paths now point to current state/architecture documents.
- Do not add new dated execution diaries here. Update PROJECT_STATE, MASTER_PLAN, the canonical GitHub Issue/PR or the relevant feature spec instead.

## Archived records

- `MASTER_PLAN_HISTORY.md` — full legacy master plan and append-only execution history.
- `README_HISTORY_2026-11-25.md` — former 63 KB status-heavy root README.
- `EXECUTION_LEDGER_2026-10-18.md` — old execution ledger snapshot.
- `ROSHAN_DEEP_RESEARCH_AND_ROADMAP_2026-10-18.md` — prior research and architecture report.
- `legacy-roadmap-2026-11-25.md` — former root-level five-item roadmap.
- `root-reports/` — Phase 8–18 and early implementation/audit reports.
